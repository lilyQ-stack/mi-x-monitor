## 程序使用
\`python douyin-monitor/collector.py --target-date 2026-11-11 --output /tmp/ellie-report\`

默认目标日期为北京时间昨天。完整运行下载视频、离线识别并在本地输出 \`manifest.json\` 和 \`<video_id>.transcript.json\`；视频识别后立即删除。

\`--only-discover\`：仅测试新作品发现及覆盖，不下载媒体。

### 输出的安全含义
- \`status=transcribed\`：找到目标日期的公开视频并完成本地识别。
- \`status=no_posts_in_accessible_feed\`：已遍历接口返回的目标日期窗口，但**不保证平台没有隐藏或省略作品**。
- 失败时进程非零退出并打印 \`COLLECTION_FAILED\`；不把失败包装成“没有更新”。

GitHub工作流仅上传最长保留7天的结果 artifact，**不上传原视频，不把逐字稿提交到公开Git历史**。
